#  Projeto de Testes Manuais - demoblaze

## Objetivo

Este projeto documenta minha abordagem de testes manuais no site https://www.demoblaze.com/, uma plataforma de e-commerce desenvolvida especificamente para treinamento de qualidade de software.
 O objetivo foi aplicar técnicas de planejamento, execução e documentação de testes, demonstrando minha capacidade de garantir a qualidade do software.

## Habilidades Demonstradas 

-   Criação de Casos de Teste (Test Cases)
- Exploração das funcionalidades do site em questão
-   Escrita de Relatórios de Bug (Bug Reports)
-   Criação de Checklist de Regressão
-   Organização de Documentação em GitHub

## Estrutura do Projeto

-   `test-cases/`: Contém os casos de teste planejados para os fluxos principais
-   `bug-reports/`: Documentação dos bugs encontrados durante a execução dos testes.
-   `checklists/`: Checklist de regressão com os testes críticos para validação de novas versões.

## Tecnologias Usadas

-   Ferramentas: GitHub, Markdown
-   Sistema Testado: demoblaze/Product Store
