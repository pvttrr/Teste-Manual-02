#  Checklist de Regressão

## Objetivo :
Basicamente o principal objetivo é verificar se as principais funcionalidades do sistema continuam funcionando corretamente após alterações, correções de bugs ou implementação de novas funcionalidades.

## Pré-condições :

-   Sistema disponível para testes.
-   Usuário de teste cadastrado.
-   Produtos disponíveis para compra.
-   Ambiente de teste configurado. 

## 1 - Navegação :
-   Verificar que a página inicial carrega corretamente sem erros.
-   Confirmar que os links do menu (Home, Phones, Laptops, Monitors) funcionam e direcionam para as categorias corretas.

## 2 - Produtos  :
-   Acessar diferentes produtos e conferir se as páginas de detalhes carregam corretamente.
-   Validar que as informações dos produtos (nome, preço, descrição) estão corretas.
-   Garantir que as imagens dos produtos são exibidas corretamente.

## 3 - Carrinho de compras :
-   Adicionar um ou mais produtos ao carrinho e verificar se o carrinho é atualizado corretamente.
-   Verificar se o valor total no carrinho está correto.
-   Remover produtos do carrinho e confirmar atualização correta.

## 4 - Finalizar compras :
-   Acessar o carrinho e iniciar o processo de compra.
-   Testar o formulário de compra, preenchendo dados como nome, país, cidade, cartão de crédito e mês/ano.
-   Confirmar que após o envio do formulário, a compra é registrada ou a mensagem de confirmação aparece corretamente.


## 5 - Login :
-   Verificar funcionalidades de login e logout.
-   Testar registro de novos usuários.
-   Validar mensagens de erro para credenciais inválidas.



## 6 - Funcionalidades Gerais : 
-   Testar o botão "Place Order" e garantir que o pedido é realizado ou mensagem exibida.
-   Checar funcionamento de pop-ups e janelas modais.
-   Validar que o site funciona corretamente em diferentes navegadores (Chrome, Firefox, etc.).
