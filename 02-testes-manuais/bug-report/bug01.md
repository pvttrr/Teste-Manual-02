#  Relatório de Bug - 01

# Finalizar Pedido Sem Todas as Informações Preenchidas

## Descrição :

É possível finalizar pedido apenas tendo preenchido o nome do usuário e o numero do cartão de crédito. 

## Passos para Reproduzir :

- Procure um produto
-  Adicione um ou mais produtos no carrinho
- Vá para guia do carrinho 
- Finalize o pedido 
- Preencha as informações apenas do "Nome" e do "Cartão de Crédito"
- Envie as informações 

## Resultado Esperado :

"Preencha todas as informações para finalizar o pedido"

## Resultado Atual :

É exibida uma mensagem de "Obrigado pela compra" e mostra uma data aleatória e as informações que foram preenchidas
