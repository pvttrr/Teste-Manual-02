#  Relatório de Bug - 02

# # Contact Us aceita formulário em branco ou incompleto 

## Descrição :

O formulário "Contact Us" pode ser enviado mesmo sem ter todas as informações preenchidas ou mesmo estando em branco. 

## Passos para Reproduzir :

- Incompleto :
	- Vá até a aba "Contact Us"
	- Preencha alguma das informações pedidas 
	- Envie o formulário 

- Em branco :
	- Vá até a aba "Contact Us"
	- Não preencha nenhuma das informações pedidas
	- Envie o formulário 

## Resultado Esperado :

- Incompleto :
"Preencha todas as informações para finalizar o pedido"

- Em branco :
"Preencha todas as informações para finalizar o pedido"

## Resultado Atual :

É exibida uma mensagem de "Obrigado pela mensagem" em ambos os casos.
